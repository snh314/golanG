# Go Utility Box

A simple, interactive Command Line Interface (CLI) application built with Go (Golang). This program acts as a multi-purpose utility box, offering a collection of handy everyday tools accessible through a single, easy-to-use main menu.

## Features

The application currently includes 4 primary utilities:

1. **Name Greeter:** Takes your name as input and returns a personalized greeting.
2. **Age Calculator:** Calculates your approximate current age by subtracting your birth year from the current year (dynamically fetched using Go's `time` package).
3. **Basic Calculator:** Performs standard arithmetic operations (Addition, Subtraction, Multiplication, Division) on two user-provided numbers.
4. **Temperature Converter:** Easily converts temperatures between Celsius and Fahrenheit using modular functions.

## Prerequisites

To run this project, you need to have Go installed on your machine.
* [Download and install Go](https://go.dev/doc/install) (version 1.16 or higher is recommended).

## How to Run

1. Clone this repository or download the `main.go` file to your local machine.
2. Open your terminal or command prompt.
3. Navigate to the directory containing the `main.go` file.
4. Run the application using the following command:

   ```bash
   go run main.go
