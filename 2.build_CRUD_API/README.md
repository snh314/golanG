
# 🎬 Build a CRUD API with Golang

A lightweight and efficient RESTful API built with Go and the `gorilla/mux` router for managing a movie database. This project demonstrates core backend engineering concepts, including HTTP routing, JSON encoding/decoding, and slice manipulation for temporary data storage.

## 🚀 Features

* **Full CRUD Operations:** Create, Read, Update, and Delete movie records.
* **Dynamic Routing:** Extracts path variables (e.g., `{id}`) accurately using Gorilla Mux.
* **JSON Serialization:** Standardized JSON formatting for seamless client-server communication.

## 🛠️ Prerequisites

* [Go](https://golang.org/doc/install) (Version 1.15 or higher)
* [Postman](https://www.postman.com/) or any other API client for testing
